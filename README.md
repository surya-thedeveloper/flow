# Flow 🌊

A fluid, minimalist task and note-taking application designed around focus, momentum, and water-like fluid dynamics.

🌐 **Live Demo**: [https://surya-thedeveloper.github.io/flow/](https://surya-thedeveloper.github.io/flow/)

---

## ✨ Features

- **Fluid Wave Progress Engine**: Real-time 60fps SVG fluid wave animations synchronized with task completion states.
- **Midnight Aesthetic**: Deep dark mode palette with glowing neon cyan/blue accents and subtle glassmorphism.
- **Intuitive Workflow**:
  - Unchecked and Completed task segregation.
  - Smooth pointer-drag task reordering.
  - One-click instant note and task deletion with fluid dissolution animations.
  - Flow momentum tracking ("Last flow at..." & completion timestamps).
- **Responsive Collapsible Sidebar**: Left-side micro scrollbar with fluid transition between expanded and collapsed vertical brand modes.
- **Local Persistence**: Zero-configuration localStorage synchronization across reloads.

## 🚀 Tech Stack

- **React 19**
- **TypeScript**
- **Vite**
- **Lucide Icons**

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/surya-thedeveloper/flow.git

# Navigate to project directory
cd flow

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```

## 🌐 Deployment

The project is configured for automated continuous deployment to GitHub Pages via GitHub Actions upon pushes to `main`.
