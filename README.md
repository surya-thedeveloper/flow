# Flow 🌊

A fluid, neuro-inclusive task and note workspace designed around **focus, sensory momentum, and cognitive ease**.

🌐 **Live Demo**: [https://surya-thedeveloper.github.io/flow/](https://surya-thedeveloper.github.io/flow/)

---

## 🧠 Why Traditional To-Do Lists Fail the ADHD & Overwhelmed Mind

Most productivity apps are built like spreadsheets disguised as checklists. For ADHD brains—and anyone dealing with cognitive overload—traditional task managers often cause more friction than clarity:

| Traditional Task Apps ❌ | The Flow Approach 🌊 |
| :--- | :--- |
| **Endless Wall of Tasks**: 20+ unchecked items trigger visual overwhelm, dread, and executive dysfunction. | **2-Item Active Viewport**: Hides the noise. You only ever face *Now* and *Next*. |
| **Guilt-Inducing Deadlines**: Red badges, overdue alerts, and missed timers induce anxiety. | **Momentum Tracking**: Replaces deadlines with positive reinforcement (*"Last flow at 2:30 PM"*). |
| **Static & Unrewarding**: Ticking a grey box provides zero tactile dopamine. | **Dynamic Water-Flow Engine**: Fluid 60fps SVG wave animations deliver instant sensory satisfaction. |
| **Clunky Bureaucracy**: Endless menus, tags, priorities, and confirmation dialogs. | **Zero Friction**: Instant drag reordering, automatic focus expansion, and one-click fluid deletions. |

## 💡 How Flow Works: Built for Neurodiversity & Deep Focus

### 1. 🎯 Defeating Choice Paralysis (The 2-Item Rule)
When you look at a list of 15 things, the brain struggles to prioritize, leading to task avoidance. Flow automatically restricts the active view to **only 2 tasks at a time**.
- Reduces decision fatigue to a binary choice: *Do task #1 or task #2*.
- The rest of your tasks wait peacefully out of sight until you're ready.

### 2. ⚡ Adaptive Brain-Dumping
- When you click into the **Add item** input, Flow intelligently opens the full list so you can brain-dump ideas without losing context.
- The second you finish typing and step away to execute, Flow smoothly contracts back into the calm, focused **2-item mode**.

### 3. 🌊 Sensory Dopamine: The Fluid Wave Engine
ADHD and creative minds thrive on immediate, engaging feedback.
- Every completed task propels a mathematical SVG water wave smoothly across the top of your workspace.
- The wave flows, ripples, and settles with cubic-bezier ease, turning mundane task completion into a soothing, rewarding sensory experience.

### 4. 🕊️ Zero Guilt, Pure Momentum
Instead of shaming you with overdue red alerts, Flow tracks your personal rhythm:
- Displays gentle flow timestamps: *"Last flow at 3:15 PM"* or *"Completed at 24/09 · 4:20 PM"*.
- Encourages continuous progress rather than punishing pauses.

### 5. 🧘 Midnight Immersion Aesthetics
- Deep OLED midnight navy palette (`#060912`) with glowing neon cyan/blue highlights designed to eliminate eye strain during late-night flow states.
- Clean typography and distraction-free micro-scrollbars keep your attention centered entirely on your work.

## ✨ Full Feature Overview

- 🌊 **60fps Fluid Wave Progress Engine**: Synchronized fluid dynamics for macro and micro task completion.
- 🗂️ **Automated Task Segmentation**: Clean separation between active queue and completed archives.
- ✋ **Smooth Pointer-Drag Reordering**: Effortlessly re-prioritize items with intuitive touch/mouse drag.
- 💨 **Fluid Dissolution Animations**: Instant one-click task and note deletion with smooth, graceful exit animations.
- 📱 **Collapsible Brand Sidebar**: Smoothly collapses into a minimalist vertical indicator with matching right-side slogan.
- 💾 **Local-First & Private**: Zero cloud tracking, zero login required. Everything is safely persisted in your browser's `localStorage`.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/surya-thedeveloper/flow.git

# Navigate to project directory
cd flow

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```
